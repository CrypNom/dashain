# Dashain 2083 Celebration Page 🌸
Open `index.html` in a browser (or host the folder anywhere). No build step.

- Change the countdown date in `js/main.js` → `VIJAYA_DASHAMI` (Nepal time, +05:45).
- Music: `audio/dashain-loop.mp3` (synthesized madal + sarangi-style loop). Replace with your own recording using the same filename.
- Blessing sound: `audio/blessing.mp3`.
- OG image / favicon: `images/`. For social previews, set absolute URLs in the og: meta tags after hosting.
- Gallery: tap a frame to add a photo (kept in-browser only). For permanent photos, set `background-image` in the frames.
- Fonts load from Google Fonts (fallbacks included for offline).
- Write-your-own wish card with shareable link (Share / Copy / WhatsApp); shared links open a received-wish card.
- Dashain Songs section links out to YouTube/Spotify (no audio files bundled). Mobile bottom tab bar added.
